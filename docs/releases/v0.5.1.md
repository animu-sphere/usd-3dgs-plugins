## Objective

Ship the public-quality follow-up to v0.5.0 without adding another input
format: synchronize installation and verification documentation, harden the
importers against hostile resource claims, and make the package-consumer path
observable on every declared hosted platform.

## What shipped

Matches the finalized `## [0.5.1]` section of
[CHANGELOG.md](../../CHANGELOG.md).

- Shared import safety limits cover Gaussian counts, checked allocation sizes,
  SOG plane dimensions and archive budgets, SPZ payloads, codebook and palette
  sizes, JSON tokens and nesting, and resolver-backed companion data.
- Hostile-input fixtures cover shared limits and JSON-depth handling, and the
  common import-statistics observability seam is available from all three
  format readers.
- SOG unbundled companion-plane metadata is checked before resolver-backed
  data is allocated, so hostile dimensions fail with a bounded diagnostic.
- The OpenStrata toolchain is pinned to 0.22.10 and the CI/runtime matrix uses
  the canonical OpenUSD 26.08 leaves with SBOM and SLSA/in-toto provenance.
- Package-origin verification runs for all three bundles in the release lane,
  and the installation guide documents checksum, manifest, SBOM, target, and
  ABI checks before manual activation.

## Compatibility and known limitations

- The release remains read-only: PLY, SPZ, and SOG are imported into the
  shared `/Asset/Splat` USD representation; export, streaming, and editing are
  unsupported.
- SOG v1, lossy WebP planes, streamed SOG layouts, spatial chunks, and LOD
  remain unsupported. SPZ v4 and binary big-endian PLY remain unsupported or
  explicitly rejected as documented by the capability matrix.
- The supported OpenUSD range remains `>=26.05,<27.0`. The release artifacts
  target the `cy2026` / `usd` profile, OpenUSD 26.08, and Python 3.13; the
  plugin must match the host platform, compiler ABI, OpenUSD build, and Python
  ABI.
- Hosted verification runs Windows at L4 and macOS arm64/Linux at L5. Broader
  consumer checks such as replacement and uninstallation behavior remain
  follow-up work.
- This repository authors Gaussian USD data but does not provide a Hydra
  renderer. Visible splats require a Gaussian-capable delegate.
