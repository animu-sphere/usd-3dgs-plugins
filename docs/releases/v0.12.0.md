# v0.12.0 — `.splat` format coverage

- **Tag** `v0.12.0`
- **Commit** `a951a8dbb2be62943304f617e2b088d01e048f2a`
- **Published** 2026-11-21 JST
- **GitHub** [v0.12.0 release](https://github.com/animu-sphere/usd-3dgs-plugins/releases/tag/v0.12.0)

The release reads headerless `.splat` files through the new `gaussian-splat`
bundle. Each Gaussian is a fixed 32-byte record: float32 position and linear
scale, 8-bit colour and opacity, and an 8-bit scalar-first rotation. One
record reader and one semantic decoder turn the records into the shared
model, and the shared layer writer authors the same stage as the PLY, SPZ,
and SOG importers, through full and metadata-only reads. The aggregate
packages now carry four member bundles.

v0.12.0 first targeted glTF `KHR_gaussian_splatting`. The
[FMT-09 spike](../reports/format-spike-gltf-gaussian-splatting-2026-11-19.md)
found no technical blocker, but the sibling `usd-gltf-plugins` already claims
`.gltf`/`.glb`, so the maintainer deferred glTF on 2026-11-19 and `.splat`,
the planned fallback, became the release format.

## Decisions

- `.splat` gets its own bundle, `gaussian-splat`, with the `GSSPLAT-`
  diagnostic prefix, rather than a second file format in `gaussian-ply`
  ([SPLAT_FORMAT.md §6](../reference/SPLAT_FORMAT.md#6-decisions)).
- Rotation bytes are read as `(b − 128) / 128` and then normalized, the exact
  inverse of every observed writer. SplatTransform's reader rule
  `b / 255 · 2 − 1` is not used. An all-zero rotation becomes identity with
  `GSSPLAT-W001`.
- Every observed writer stores the Graphdeco PLY frame (RDF), so the decoder
  applies the shared `FlipYZAxes`, as PLY and SOG do.
- A headerless format can only be routed by extension and size. `CanRead()`
  accepts a `.splat` path with a non-zero size that is a multiple of 32;
  `Read()` refuses a renamed PLY, SPZ v4, ZIP or SOG, or GLB file with
  `GSSPLAT-E003`, naming the format.
- The bundle adds no third-party dependency.

## Known limitations

- `.splat` stores only the base colour, so every import has SH degree 0.
  Colour, opacity, and rotation are 8-bit; rotation error reaches 1.75° for
  truncating writers. A byte holds DC only within about ±1.7725, and 25-32 %
  of the Gaussians in the committed CC0 corpus have at least one clipped
  channel ([SPLAT_MAPPING.md](../reference/SPLAT_MAPPING.md)).
- OpenUSD chooses a file format by extension only. If another plugin in the
  same runtime registers `splat`, install `gaussian-splat` deliberately.
- `.splat` is covered by synthetic fixtures, CC0 corpus conversions, and
  SplatTransform's test file; no redistributable real-world capture was
  found. The benchmark corpus has no `.splat` rows yet
  ([backlog](../roadmap/backlog.md#performance-and-loading)).
- glTF `KHR_gaussian_splatting` is deferred and `.ksplat` is unsupported;
  the [backlog](../roadmap/backlog.md#other-format-candidates) records both.
