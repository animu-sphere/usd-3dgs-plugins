## Changes

- PLY, SPZ, and both SOG layouts compose through anchored USD references
  and whole-asset payloads. Repeated instanceable references share a prototype
  and support independent root transforms. Native USDZ retains payload loading
  behavior and the Gaussian arrays.
  [Composition guide](../guides/COMPOSITION.md)
- `/Asset` is the default prim and `Splat` is its Gaussian child. Import
  metadata records the format, count, and SH degree on `/Asset`. An embedded
  SOG source can be referenced by a USD entry layer through the SOG importer.
  [Workspace contract](../architecture/WORKSPACE.md#5-authored-stage-contract) ·
  [Resolver matrix](../reference/RESOLVER_MATRIX.md)
- Workspace and standalone builds share OpenUSD linking, plugin staging and
  installation, and Python CTest runtime setup.
  [PR #54](https://github.com/animu-sphere/usd-3dgs-plugins/pull/54)

## Compatibility

The distributed binaries target OpenUSD 26.08 and Python 3.13 and must match
the host ABI. Convert captures to native USD layers for USDZ delivery. PLY
and SPZ source imports require filesystem access, and loading a Gaussian
payload imports all arrays for the asset. Drawing splats requires a compatible
Hydra delegate.
[Supported configurations](../reference/SUPPORTED_CONFIGURATIONS.md) ·
[Composition guide](../guides/COMPOSITION.md)
