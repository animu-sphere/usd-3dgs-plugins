## Changes

- Extended hostile-input fixtures for PLY, SPZ, and SOG. SPZ rejects oversized
  sources before the bulk read, and bundled SOG rejects oversized `meta.json`
  before extraction. [Import limits](../reference/IMPORT_LIMITS.md)
- SOG opens its primary asset through the resolver, including package-relative
  paths and custom URI resolvers. Companions resolve relative to `meta.json`.
  All three readers accept UTF-8 paths on Windows. The SOG decoder also retains
  its resolver callbacks in optimized MSVC 19.51 C++20 builds.
  [Resolver matrix](../reference/RESOLVER_MATRIX.md)
- Added a benchmark corpus with resource limits and a generated scale ladder
  up to 7,995,392 Gaussians. Hosted CI runs the 1M step in all three formats,
  and the 4M and near-ceiling steps passed locally on Windows.
  [Benchmark corpus](../reference/BENCHMARK_CORPUS.md)
- Added aggregate package installation, prefix switching, and removal checks
  to the release workflow. Python and C++ consumers open packaged fixtures,
  and `usdchecker` validates the USD produced by `usdcat`.
  [Installation checks](../guides/INSTALL.md#verify-the-aggregate-installation)
- Documented stable diagnostic-code lookup and opt-in import summaries.
  [Import diagnostics](../reference/DIAGNOSTICS.md)

## Compatibility

The binaries target OpenUSD 26.08 and Python 3.13 and must match the host ABI.
Import is read-only and fully materializes the asset. The supported source
variants and resource bounds are listed in the
[capability matrix](../reference/CAPABILITY_MATRIX.md) and
[import limits](../reference/IMPORT_LIMITS.md). Drawing splats requires a
Hydra delegate that supports `ParticleField3DGaussianSplat`.
