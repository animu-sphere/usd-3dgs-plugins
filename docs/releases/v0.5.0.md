# v0.5.0 — SOG v2 one-object import

- **Tag:** `v0.5.0`
- **Commit:** `9e3e012a43e08c626e0240abf5c063d53f4c5d30`
- **Date:** 2026-07-25
- **Status:** tagged; hosted release lane pending

## Objective

Ship the first format built on the v0.4.0 Gaussian Import Foundation contract:
one complete PlayCanvas SOG v2 object, in both the bundled `.sog` and unbundled
`meta.json` layouts, authored through the same USD representation as PLY and
SPZ.

## What shipped

Matches the finalized `## [0.5.0]` section of
[CHANGELOG.md](../../CHANGELOG.md).

- SOG v2 ZIP and unbundled readers, including strict metadata routing and
  resolver-backed companion-plane loading.
- Lossless WebP property-plane decoding, SOG codebook/dequantization, SH
  degrees 0–3, and RDF→RUB conversion through the shared model contract.
- Stable `GSSOG-****` diagnostics and a machine-readable diagnostics catalog.
- PLY/SPZ/SOG equivalence triples and provenance-recorded real SOG corpus assets.
- `gaussian-sog` promoted from the v0.4.0 skeleton into the release matrix;
  the bundle is built and packaged for all three declared hosts.
- OpenStrata CI/release pin updated to **0.20.0**, including package-origin L5
  support observed locally.

## Compatibility and known limitations

- Read-only import only; SOG export, streaming, spatial chunks, and LOD remain
  unsupported.
- Lossy WebP and legacy SOG v1 are rejected with explicit diagnostics.
- Windows remains capped at OST L4 in hosted CI; macOS/Linux are declared at
  L5 pending hosted confirmation.
- SOG performance baselines over the committed real-asset corpus remain to be
  measured.
- The authored model frame is RUB / Y-up, consistent with v0.4.0 and the
  shared contract.
