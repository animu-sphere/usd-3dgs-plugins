# v0.9.0 — Rendering integration preview

- **Tag** `v0.9.0`
- **Commit** `14d2f0be40b932d46016c9f87a6b1d1967d56356`
- **Published** 2026-11-16 JST
- **GitHub** [v0.9.0 release](https://github.com/animu-sphere/usd-3dgs-plugins/releases/tag/v0.9.0)

The release adds a verified experimental rendering integration and publishes
the three import bundles as an aggregate plugin product. The viewport preview
uses the separate, locked Windows `lookdev` Formation with `gaussian-ply`
v0.8.0 and hdMerlin v0.16.6. The release's `usd` products cover import and
stage inspection. SPZ and SOG rendering were outside the preview's test scope.
[Merlin's run instructions and evidence](https://github.com/animu-sphere/hydra-merlin/blob/ad4bc6a44b3e6c01c536366b1971a62d9d88f659/formations/gaussian-host-session/README.md#verification)
