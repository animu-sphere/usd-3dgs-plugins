# v0.13.0 — SOG v3 and benchmark coverage

- **Tag** `v0.13.0`
- **Commit** `68663927c66ce8c3c632ee668d51525210b3de3e`
- **Published** 2026-11-21 JST
- **GitHub** [v0.13.0 release](https://github.com/animu-sphere/usd-3dgs-plugins/releases/tag/v0.13.0)

The release reads SOG version 3 through the existing `gaussian-sog` bundle,
alongside version 2, in both the bundled and unbundled layouts. SOG v3 has
been the default output of PlayCanvas SplatTransform since 3.11.0, and
v0.12.0 refused it with `GSSOG-E003`. Version 3 changes three encodings:
rotation is an exponential map, opacity is `(a / 204)²` and can exceed 1,
and palette labels are 24-bit. Everything else decodes as in v2 and is
authored through the shared layer writer. The benchmark corpus now measures
SOG v3 and `.splat` in every tier, alongside PLY, SPZ, and SOG v2.

## Decisions

The maintainer accepted these on 2026-11-21, from the
[spike's §9](../reports/format-spike-sog-v3-2026-11-21.md#9-proposed-scope-for-fmt-17-and-fmt-18):

- A v3 opacity above 1 is clamped to 1 with `GSSOG-W002`, as the
  specification requires of a renderer without over-unity support. The model
  keeps opacity in `[0, 1]`.
- A 4th SH band is rejected with `GSSOG-E007` rather than truncated, because
  the model stops at degree 3.
- SplatTransform 3.11.0 and 3.11.1 wrote `version: 3` with rotations in alpha
  channels and no `quats`; 3.11.2 changed the layout without changing the
  version. Such a file is refused with `GSSOG-E003`, which asks for a
  re-export. The unbundled routing gate still claims it so the message is
  seen.
- Blind textures are validated and ignored with `GSSOG-W003`; `extras` and
  `comments` are ignored silently.
- A `model` of `antialiased` or `2dgs` is ignored with `GSSOG-W004` in both
  versions. This is the one v2 change: such files imported silently before.

## Benchmark coverage

PERF-01 ([PR #85](https://github.com/animu-sphere/usd-3dgs-plugins/pull/85))
added SOG v3 and `.splat` to the fixture, corpus, scale, and real tiers of the
[benchmark corpus](../reference/BENCHMARK_CORPUS.md). The hosted gate grew
from 12 to 20 rows, and every row met the existing targets, so none was
revised. In the
[PR's final source CI run](https://github.com/animu-sphere/usd-3dgs-plugins/actions/runs/44885722082),
all 20 rows passed on each runner:

| Runner | Max `CanRead()` | Max metadata-only | 1M `Stage.Open`, SOG v2 / v3 / `.splat` (s) | 1M peak resident, SOG v2 / v3 / `.splat` (GiB) |
| --- | ---: | ---: | ---: | ---: |
| Windows x86_64 | 0.35 ms | 20.3 ms | 0.884 / 0.910 / 0.237 | 0.473 / 0.473 / 0.141 |
| macOS arm64 | 0.33 ms | 15.3 ms | 0.386 / 0.444 / 0.088 | 0.569 / 0.585 / 0.199 |
| Linux x86_64 | 0.23 ms | 20.4 ms | 0.576 / 0.573 / 0.101 | 0.587 / 0.587 / 0.184 |

SOG v3 costs the same as v2. `.splat` is the cheapest encoding because it
carries no rest SH. The local 4M, ceiling, and real-tier rows are in
[BENCHMARK_CORPUS.md](../reference/BENCHMARK_CORPUS.md#v0130-additions).

## Known limitations

- SOG v3 files from SplatTransform 3.11.0 and 3.11.1 do not open; re-export
  them with 3.11.2 or later. SOG v3 with 4 SH bands does not open either.
- Opacity above 1, blind data, and the render model are not carried onto the
  stage. A renderer that needs them must read the source file.
- SOG v3 is a new format whose layout changed once within one version number.
  This release follows the specification as read on 2026-11-21 and
  SplatTransform v3.12.0 (`5d5be2b`).
- Real v3 coverage is the CC0 corpus converted with SplatTransform; no
  independently produced v3 capture was found.
- Streamed SOG, `.ksplat`, and glTF `KHR_gaussian_splatting` remain
  unsupported; the [backlog](../roadmap/backlog.md#other-format-candidates)
  records them.
